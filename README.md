# [Team] 롤 게시판 프로젝트_김성민, 육현승, 최서현

## 1. 프로젝트 소개
*** 
이 프로젝트는 Java, Oracle, Spring을 중심으로 웹 페이지 개발, 
특히 게시판을 생성하는 데에 초점을 맞춘 프로젝트입니다. 
웹 페이지 개발(CRUD)의 기본을 학습하고 능력껏 구현하기 위해 이 프로젝트를
진행하였으며, 셋 모두의 관심사이자 게시판 문화가
주로 자리잡아있는 게임을 주제로 선정하였습니다.


## 2. 사용 기술
- **Backend**: Java, Spring Boot, MyBatis, Lombok
- **Database**: Oracle
- **Frontend**: HTML/CSS, JavaScript, Thymeleaf
- **Others**: Git, GitHub

## 3. 팀원 역할
| 이름      | 맡은 역할                    |
|---------|--------------------------|
| 김성민     | 자유 게시판                   |
| 육현승(팀장) | header, footer, 패치노트 게시판 |
| 최서현     | QnA 게시판                  |
